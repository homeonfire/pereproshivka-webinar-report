# pereproshivka-webinar-report

Статическая страница отчёта по вебинару.

## Технологии

HTML, CSS и JavaScript. Установка зависимостей и сборка не требуются.

## Размещение

Входной файл сайта — `index.html` в корне репозитория. Для GitHub Pages используется ветка `main` и каталог `/ (root)`.

Файл `.nojekyll` отключает обработку статических файлов через Jekyll.
