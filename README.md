## Как открыть и использовать

Откройте `index.html` в браузере или перейдите по ссылке выше. Стили, скрипты и агрегированные данные встроены в файл; установка зависимостей и сервер не требуются.

Доступны общий раздел «Динамика», отдельные дни, источники и подисточники регистрации, каналы входа, графики онлайна, кнопки и методика. Таблицы поддерживают поиск и сортировку; есть экспорт агрегатов в CSV, копирование отчёта для Telegram и печать / сохранение в PDF.
