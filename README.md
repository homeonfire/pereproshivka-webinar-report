# Перепрошивка 2.0 — отчёт по вебинару

Интерактивная страница с результатами **первого дня вебинара 3 ноября 2026 года**. Срез данных — **4 ноября 2026 года**.

## Открытие

Откройте `index.html` в браузере. Все стили, скрипты и агрегированные данные встроены в файл: сборка, установка зависимостей и сервер не требуются. Этот же файл предназначен для размещения на GitHub Pages.

Страница содержит фиксированный срез и не обновляет показатели автоматически.

## Что есть в отчёте

- Ключевые показатели и переход от регистрации к чекину.
- Источники первой регистрации, подисточники и конверсии по ним; доступны поиск, фильтр и сортировка.
- Динамика регистраций и одновременного онлайна.
- Аудитории Telegram и MAX, каналы входа на эфир.
- Результативность трёх доводящих рассылок.
- Время просмотра, активность чата и нажатия на кнопки.
- Три среза кнопок: источник чекина, канал входа и источник регистрации.
- Покрытие сопоставления и подробная методика.

Есть выгрузка агрегатов в CSV, копирование текстового отчёта и печать / сохранение в PDF через браузер.

## Определения и ограничения

**Регистрации:** 510 заказов относятся к **471 уникальному пользователю GetCourse**. Для источника пользователя выбран самый ранний регистрационный заказ; исторические поля `user_utm_*` не используются.

**Чекины:** всего 263 пользователя. Из них **241** найден в выгрузке регистраций, ещё **22** находятся вне этой базы. Конверсия регистрации в чекин — **241 / 471 = 51,2%**. Выгрузки включают записи после окончания эфира; чекин сам по себе не подтверждает просмотр.

**Просмотры и кнопки:** учитываются 262 зрительских ID Bizon365; 140 из них нажали хотя бы одну кнопку. Повторное нажатие одной кнопки тем же ID не увеличивает счётчик. Несколько зрительских ID могут относиться к одному человеку.

**Атрибуция кнопок частичная.** С чекинами сопоставлены 70 из 262 зрительских ID и 39 из 140 кликнувших ID. Непустой источник чекина известен у 38 кликнувших; остальные относятся к строке «Источник не установлен». Покрытие другого среза может отличаться и показано прямо над таблицей. Распределение сопоставленной части не переносится на всю аудиторию.

**Мессенджеры и рассылки:** 344 входа в Telegram и 111 в MAX не складываются в уникальный охват. 156 — сумма кликнувших по трём рассылкам с возможными повторами между сообщениями. Клик по ссылке не равен просмотру эфира.
